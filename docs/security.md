# 安全和信任模型

首次 source 由用户显式选择。运行时下载权限与技能研究时联网权限是两回事，network:true 不授权上传本地资料。包不执行安装钩子、shell 或动态模块；技能导出仅接受 Markdown/JSON 指令资源。

固定 sourceIdentity、catalogRevision、source revision、SHA-256 和 adapter 摘要。相同版本换字节、换来源、换主机或重定向均失败。HTTPS 默认不附带用户凭证；401/403 返回访问失败，不自动切换账号，不输出令牌。私有源应通过现有已认证 Git 工具手工检出为本地源，不把 token 放 URL。

SHA-256 仅证明字节与预期一致；目录所在仓库的初始信任由用户选择建立，本版没有发布签名。不能把同一个恶意来源给出的摘要当成身份保证。

输入边界：单文件 2 MiB，总归档/展开树 16 MiB，最多 512 项，膨胀比不超过 100。路径限制每段 100 字符、相对路径 200 字符；拒绝绝对路径、盘符、UNC、反斜线、..、控制字符、ADS、Windows 保留名、大小写/Unicode 冲突、符号链接/重解析点、硬链接和特殊文件。限制是保守的跨平台子集；超长合法路径也会被拒绝。

升级/回滚/恢复都比较新增、修改、删除、空目录和类型变化；不接管未登记技能目录。全局和项目同名技能可能同时显示，所以先检测并阻止可见的全局/祖先同名冲突，不假设项目覆盖全局。管理员/系统/plugin 中动态来源可能不在文件扫描范围；首次宿主扫描需人工确认没有重复名称。

排他事务锁防止本工具并发写。外部编辑器仍可能在最后检查与重命名间写入；应用前关闭相关宿主/编辑器，工具不宣称对恶意并发写完全免疫。只操作拥有的技能目录，保留旧快照和异常现场。

依赖只有 jsonschema 及其必要依赖，用户已授权项目环境安装，精确版本见 requirements.lock。使用 PyPI 标准 TLS 下载，版本锁不是签名或 hash 锁。没有遥测、后台进程、定时任务和自动应用更新。
