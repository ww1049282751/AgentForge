# ADR 0001：Python 单运行时与可恢复文件事务

日期：2026-10-24。状态：采用。

空仓库没有既有技术栈。本机 Python 3.12.10、Node 24.19.0、Git、GitHub CLI 和 Codex CLI 0.164.0 可用；af 命令未发现冲突。选择 Python 3.12+ 标准库处理 CLI、JSON、ZIP、HTTPS、散列和文件事务，避免两套运行时。

完整 Draft 2020-12 校验采用 jsonschema 4.26.0 及必要传递依赖，用户已确认，仅装到本项目 .venv。自定义语义检查不冒充 JSON Schema 引擎；schema 引用注册表不联网。版本全锁定，供应链签名和 hash 锁另属后续增强。

选择两次同卷目录重命名和完整快照日志，避免 Windows 非空目录原子覆盖限制。取舍是短暂路径缺口与更高磁盘占用；应用前关闭宿主读取，不宣称热更新或严格原子切换。日志、checksum、保留旧目录及恢复命令共同提供进程中断可恢复性。

默认项目 pin，独立导出而非指向用户级目录的链接，避免其他项目更新间接改变当前项目行为。先支持一个 Codex 指令型技能，原生插件分发留作单独适配。
