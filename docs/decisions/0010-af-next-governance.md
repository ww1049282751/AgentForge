# ADR 0010：AF Next 第一阶段治理与验证

日期：2026-10-25。状态：按用户交接要求实施仓库治理；效果结论见 [本轮证据](../evidence/af-next-phase1-summary.md)。

## 背景与决定

实际基线为 `c2c770babe10801dc5eeed197beb78440ba300fb`，工作区干净。已有五技能具备专业边界和四层质量协议，但根规则混有多次单次安装授权，缺少能力资产分流、选择/组合干扰和跨阶段交接的集中说明。历史 no-change、inconclusive 和未执行项不足以支持扩大技能集合；这些是治理缺口与待验证风险，不冒称本轮已观察到模型失败。

- 延续 [ADR 0004](0004-personal-skill-collection.md)：个人技能集合，唯一作者源；零新技能、零运行时依赖、无安装器或调度平台。
- 将历史操作授权留在验证记录与原证据中，根规则只保留持久约束与准确索引。历史记录不是当前授权。
- 用 Skill / Policy / Knowledge / Tool / Context / Evaluation 帮助选择最简单载体；在作者规范及创建器已有参考中局部补充，不重写五个入口。
- 交接仅在信息可能丢失时使用，保留来源性质、决策主体/状态、实际执行、未知及失效条件，不建立统一交接 schema。
- 扩展现有 AF Skill Quality Loop，区分显式加载、宿主隐式选择与普通基线，记录负担及保留/收窄/合并/退场候选；不创建第二协议或生命周期注册表。

## 替代与后果

维持原状最省改动，但历史授权和跨阶段证据边界仍依赖临场判断。新增交接/计划/验证技能或统一执行器会扩大维护负担，现有证据尚未说明其独立必要性。仅扩 docs 最轻，但创建器离开仓库后无法使用分流/退场判断；因此在其两份既有参考中保留简短、自包含的原则，不增加跨目录依赖。

风险是新术语和说明增加阅读负担、交接结构没有净收益，或过度分流阻碍合理技能化。用同条件合成对照和已有方案/复用场景检查，保留负面结果；治理材料通过、行为表现、相对收益和个人价值分开判定。若长期无增益，优先缩减说明，而非增加模板。

本轮只实施本地文件、轻量检查及可完成的受控验证。不安装或同步用户副本，不提交、推送、合并、发布、部署或改宿主配置；这些操作须另有当前明确授权。第二阶段候选只有在真实任务暴露独立且可复用的缺口、合理替代不足且维护代价可接受时再评估，不设期限或占位目录。
