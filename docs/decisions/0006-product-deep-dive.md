# ADR 0006：独立的产品深度研究技能

日期：2026-10-25。状态：已采纳。依据：本次用户实施交接要求；延续 [个人技能集合](0004-personal-skill-collection.md)，不重建安装/分发基础设施。

## 决定

在 `skills/product-deep-dive/` 新建独立技能，回答具体产品如何工作、源码如何实现、设计取舍及可复用机制。product-intelligence 继续负责方向、需求机会、竞品范式与方案选择，其研究方法和历史结论不改写；仅调整入口的职责说明。

新技能以轻入口选择四种研究模式，五份参考材料分别负责研究推进、产品/交互模型、源码/架构、证据验证和模式提取。将交互并入产品模型、技术架构并入源码分析，避免复制方法。五份模板按需使用；示例和评估输入明确标为合成。

E1–E5 记录依据类型而非可信度排名；源码存在、路径可达、测试通过、运行验证和生产启用分别取证。研究通常在会话交付，知识保存与更新服从用户授权，不要求每次迁移到用户项目。

## 边界与后果

本决定将此前 [产品研究单入口](0005-layered-product-research.md) 的范围细化为两个独立任务入口，不撤销 product-intelligence 已有的机制分析能力，也不影响其历史验证结论。混合任务可复用有证据边界的成果，不自动调用另一个技能，不在技能内部链接外部技能源，完整文件夹可独立复制。

只维护仓库作者源；此次不安装新技能，不同步已存在的用户级副本，不推送、发布或启用后台任务。独立合成任务试跑用于发现行为问题，不等于真实产品研究、自动触发或用户净收益已证明；实际状态见 [验证报告](../validation-report.md)。

后续授权：2026-10-25 用户要求先备份并保护现有改动，再全局安装 product-deep-dive、同步 product-intelligence，并提交推送。已按授权完成两个用户级副本的安装/同步与散列核对；远端执行结果见验证报告。上段描述新增技能阶段的边界，不覆盖后续授权；唯一作者源、非自动同步和未验证项保持不变。
