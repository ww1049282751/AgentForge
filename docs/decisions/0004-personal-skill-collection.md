# ADR 0004：精简为个人技能集合

日期：2026-10-25。状态：用户明确要求执行。

## 背景

用户明确：“安装器不需要了，仓库就是多个技能的集合，目标是个人使用”，随后授权移除安装器相关内容，保留现有技能和研究资料，并同步维护规则。

此前增加一份分析方法还需要同步技能/插件版本、处理安装目录冲突和运行安装器回归，这些维护步骤不服务于当前的技能使用目标。此判断针对当前个人需求，不否定旧运行时历史上已经实现的安全能力。

## 决定

- skills/<name>/ 是唯一编写源；保留 SKILL.md、方法、模板及相关案例和行为评估材料。
- 移除安装器代码、适配器、插件包装、分发目录、schema、包元数据、版本锁及其专属测试和打包配置。
- 保留标准库实现的轻量格式与引用检查；按用户后续授权，CI 同时运行这些检查的轻量回归及技能专属材料测试，不安装运行时依赖。
- 将产品研究案例和行为场景归入对应技能。保留真实研究摘要、原始私有材料、历史决定和验证证据。
- 移除前建立包含未提交修改的文件快照并逐文件校验。既有本机使用副本不自动删除或覆盖；旧安装状态、环境和构建产物进入本地备份。
- 用 Git 历史或内容散列定位技能快照，不再要求每个技能维护发布版本、渠道或依赖关系。
- 暂停远程推送与发布的约束继续有效。

后续授权记录：2026-10-25 用户明确要求将全部现有调整同步到远端，允许本次仓库推送；上文暂停状态保留为本决定作出时的记录，不覆盖后续用户授权。版本发布、Release/tag 和后台更新不在本次授权范围内。

## 替代关系

本决定替代 [ADR 0001](0001-runtime-choice.md) 的当前运行时选择，以及 [ADR 0002](0002-personal-skill-first.md) 中保留运行时备用、原生插件实验和基础设施复核安排。

[ADR 0003](0003-product-research-positioning.md) 的产品研究定位继续有效；其中安装器、插件版本和发布流程仅保留为历史事实。旧决定不再向当前任务授予或要求安装器操作。

## 验证边界

本次验证文件保留、迁移后的引用、技能结构和轻量检查行为。它不验证新的真实研究收益，也不代表宿主自动发现、跨平台运行或外部技能副本同步。实际执行结果见 [验证报告](../validation-report.md)。
