# ADR 0002：个人使用优先，先验证技能价值

日期：2026-10-24。状态：用户已确认。变更：替代初始实施计划的工作优先级；不否定 ADR 0001 对已有运行时的技术选择。

## 背景与证据

工程链路已实现，45 项运行时回归中 44 通过、1 跳过；实际宿主发现通过，但真实任务价值尚未验证。第三方评审指出工作量集中在安装/更新基础设施，技能质量风险排在后面。用户要求按此方向调整。

本机 CLI 已显示原生插件和 marketplace 的管理能力，值得后续用最小实验检查覆盖范围。但当前没有证据证明原生系统等价覆盖所有自定义 pin/回滚需求，也没有证据支持“30 行即可替代”或“减少 70% 工时”的估算。两者都不作为本决策的事实依据。

## 决定

- AgentForge 当前面向维护者个人的真实产研任务，不按公共分发产品设计首版。
- 自建运行时冻结扩展，保留现有代码与保护机制，暂不删除或重写。
- 优先以相同模型、材料、工具条件对照普通回答与技能回答，观察证据准确性、认知增量、行动性和成本。
- 原生插件最小验证排在真实任务评估之后。只有实际遇到且用户需要的缺口才支持继续投入基础设施。
- 暂不推送。项目文档、评估记录和代码都留在本地，真实材料默认不进入 Git。

## 后果与复核

已有运行时仍可使用，但工程功能完成度不再等于当前产品阶段完成度。技能描述/模板/流程只根据观察到的失败定向调整，按既有版本规则处理，不因一次好结果宣称普遍有效。

当首批真实任务形成结论时重新审视：是否有可重复的决策收益、成本是否可接受、哪些原生能力已足够、哪些缺口值得自建。可以决定简化或放弃某项已有基础设施；不自动要求将其全部产品化。
