# ADR 0003：产品探索、深度研究与认知拓展

维护说明：本记录的产品研究定位继续有效；包版本、安装器与原生插件安排为历史状态，现按 [ADR 0004](0004-personal-skill-collection.md) 维护个人技能集合。

日期：2026-10-24。状态：用户明确定位反馈已采纳；效果仍需复验。

## 依据

用户在另一个新会话体验 Product Intelligence 后明确：定位包括产品发散性调研、深入分析、竞品分析、专家评审与认知补齐；输入不清楚时应多次追问以对齐方向，产出更丰富、可适当使用图表、更有建设性和突破性。

本次未读取该新会话的原始输出，因此只把这段话作为用户明确的产品偏好与修改依据，不推测那次体验具体发生了什么错误。

此前 workbench-01 是研究者拟题的“当前价值与最小行动”，且受离线和字数目标限制，不能充分检验上述定位。两组 10/10 仅针对当时量表，不代表已经满足用户期望，也不据此否认技能的潜在价值。

## 改动

- 从默认决策简报扩展为开放探索、机制深挖、竞品对照、专家/专业视角评审和认知补齐；用户明确要短答时仍提供简报。
- 分轮澄清关键未知，复用已有答案、识别分歧；不以一轮问答或自行拟题替代方向对齐。用户明确不要继续问时按其要求保留假设推进。
- 允许并鼓励有根据的发散与突破性假设，同时说明条件、反对论证和证据获取方式；不一律收敛为最小 MVP。
- 完整报告可使用机制图、方向图与对照表；定性判断标注为判断，不伪造定量证据。
- 区分有来源的真实专家观点、理论应用和 Agent 模拟视角；不虚构真人评审或背书。
- 增加匹配定位的行为检查，保留历史结果；单次受控试跑不替代用户价值反馈。

## 版本与边界

skill 与内部 plugin 均升级到 0.2.0，插件精确引用 skill 0.2.0；runtime 仍为 0.1.0 且冻结扩展。按 MINOR 处理：新增研究模式与资源，明确短答请求继续兼容，不改变安装布局、权限、源格式或已有 CLI 契约。现有项目安装通过已有事务更新并保留备份，不手改导出内容。

保持个人使用优先、原生插件验证后置、真实材料本地保留、暂不推送。此反馈不授权开展产研工作台开发，也不授权联系真人专家。
