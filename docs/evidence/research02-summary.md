# research-02：定位调整后的受控行为复核

日期：2026-10-24。版本：skill / 内部 plugin 0.2.0；runtime 0.1.0。

## 目的与方法

依据用户明确反馈，检查分轮澄清、探索深度、建设性与丰富表达是否出现在新版行为中。版本依据见 [ADR 0003](../decisions/0003-product-research-positioning.md)。

两个独立子代理显式读取冻结的项目技能导出：一个接收两轮脚本输入，另一个在明确研究范围、不继续提问的条件下，读取四份冻结真实项目材料并离线生成报告。主代理复核实际输出；这不是独立盲评、真实用户访谈或新增真实任务成功样本。原始输入、输出、执行记录和七个导出文件的 SHA-256 留在忽略的 `.local/skill-evals/2026-10-24/research-02/`。

## 实际观察

| 检查 | 观察与边界 |
| --- | --- |
| 第一轮模糊输入 | 面对仅有产品名称的输入，询问使用对象、触发场景与研究目标；没有自行认定痛点或直接给方案 |
| 第二轮仍不明确 | 复用个人优先、可能产品化等已有答案，继续询问具体经历与“突破性”的含义；没有把一次回答当作完成对齐 |
| 发散与深挖 | 报告提出四种具有不同使用时刻、机制和取舍的产品范式，解释潜在价值成立条件、替代解释与失败信号；不是功能换名清单 |
| 建设性与认知增量 | 从记录结构延伸到判断反馈、知识适用条件与分歧处理，保留近期观察、中期差异化和长期探索；没有统一压缩为最小 MVP |
| 专业视角 | 四种专业视角围绕同一选择提出异议、修正和改变判断的证据，明确标记为 Agent 模拟；没有虚构真人参与 |
| 表达与证据 | 使用定性范式对照表、机制流程图和证据账本；因果机制标为假设，没有伪造量化收益或排名 |
| 竞品范围 | 明确为范式比较，未伪装成真实竞品调查；未验证当前市场、价格或实际产品体验 |

丰富报告生成曾因耗时较长被中断，随后恢复并完成；恢复时加入篇幅约束。该过程已保留在执行记录中，不能作为稳定响应时延或一次自然完成的证据。没有可靠的精确模型、token 或费用数据。

## 工程验证与结论

包与 schema 校验通过，技能 quick_validate 通过。完整运行时回归共 45 项：44 通过，1 项因 Windows 文件符号链接权限跳过；见 [本轮完整日志](research02-runtime-tests.txt)。测试夹具显式固定起始版本为 0.1.0，使原有版本生命周期测试不随技能当前版本漂移；未修改运行时代码。

本轮支持“新增要求已进入受控输出行为”，不能证明稳定的真实用户净收益、更有突破性的实际成果或优于普通对话。也未验证自动触发、原生插件加载、在线竞品研究或真人专家评审。下一步应由用户在真实任务中判断方向是否对齐、是否形成新理解、建议是否有帮助及篇幅负担；不得据此启动冻结的基础设施扩展。
