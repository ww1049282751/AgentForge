# product-intelligence 行为试跑 — 2026-10-25

本轮实际执行了新场景中的六项，并针对发现的问题修改指令、复验和增加跨领域场景。输入均为明确标注的合成离线材料；这是模型行为试跑，不是真实用户研究，也不是在线竞品调研。

## 执行与证据

- 首轮六项分别是：功能请求与用户任务、竞品未说明的能力、竞争性解释、机制迁移、限定范围的小问题、研究收束。没有运行全部场景，也没有测试三个负例的自动触发。
- 每项执行使用新代理上下文，只提供冻结技能、请求和原始输入；不主动提供评分标准、预期答案或其他回答。执行者仍可按技能路由主动读参考材料。case03 首轮读取了分析正反例，因此不能把这一例称为未接触示例的迁移验证。
- 首轮 case01 自报方法材料在工具显示中截断。上下文隔离、文件读取与工具副作用按执行记录检查，没有对完整工具日志作独立审计。
- 执行者继承当前模型设置，没有模型覆盖；精确模型版本、token 与费用不可得，记为未知。没有不使用技能的普通组，不能由本轮结果归因技能净增益。
- 输入、未经编辑的回答、执行记录、两次修改的冻结快照与散列、独立评审均留在忽略的 `.local/skill-evals/behavior-round-20261025-4e819ba9/`。首轮原始评审保留不改。

## 实际观察

| 目标 | 输出中出现的行为 | 结论边界 |
| --- | --- | --- |
| 深入分析 | 把“自动搜集竞品资料”拆成找资料、比较口径、结论复核等解释；说明各自需要什么证据才能决定优先级 | 识别出不同机制，不代表已测出真实主要瓶颈 |
| 有效发散 | 提出按问题补证据、比较口径辅助、让结论携带证据等方向；价值环节、必要条件、代价和失败信号不同 | 是有依据的产品假设，没有采用、付费或市场规模证据 |
| 有启发的竞品研究 | 比较固定字段组织与按任务步骤组织资料的机制；讨论如何将步骤关系迁移到结论—证据关系，并考虑核对负担与迁移成本 | 两个竞品是虚构材料，未核验真实产品，也不代表选样或网络研究能力通过 |
| 证据边界 | 未把“材料没介绍某能力”写成“不支持”；没有将宣传与满意摘要当作效果证据 | 只说明这些已读回答中的表现 |
| 适度收束 | 小问题直接给条件比较；重复宣传无法补足行为证据时，明确停止并说明需要哪些不同证据 | 不要求所有回答都变成长报告或收缩为最小方案 |

一个具体认知增量是：两个功能都叫“审批”，却可能分别发生于发布前和发布后，按功能名称打勾会掩盖差异。回答因此将比较单位推进到触发时点、执行者、动作后果与证据，而不是继续扩展功能列表；同时保留“确认发生于发布前，不足以证明它能阻止发布”的边界。

## 发现的问题与修正

首轮独立审查认为六项全部达到原始场景标准。主代理另发现 case03、case04、case06 把来源 W3 中一次局部交接任务带入了当前研究：例如“近期先解决已限定的交接选择”“先解决本次交接的可行性”。这是原标准未充分捕捉的范围问题，不能改写成首轮独立审查已经判失败。

第一步修改在技能入口、澄清指导和正反例中区分本轮用户请求与资料中的局部意图：局部记录可支持需求线索，不能自行限定整项研究或成为优先行动。三个原题保持请求和输入不变，以新上下文复验。

独立复验认为三个回答均满足原始标准；新增范围标准下，case03、case04 达到，case06 部分达到。case04 的局部形式比较服务于机制迁移条件，未强行扣分；case06 虽然声明局部记录不限制研究，却仍在末尾提出“若这次交接现在必须继续……可以暂用……”的附带方案。声明边界不足以保证正文守住边界。

第二步只补充交付前的相关性检查：逐段检查建议是否回答当前请求，删除替材料角色完成其他决定的段落；添加“如果现在需要”不能使无关建议变相关。只对仍有问题的研究收束题再次复验。另用教师备课的新输入检验混合记录的范围对齐，避免只适配原研究工具的用语。

备课迁移案例达到探索目标与新增范围标准：实际展开教学依赖检查、演示资源补缺、复用条件记忆、多载体协作四种方向，没有替教师作打印或页面决定。独立审查另指出一句“资料收集完成就意味着备课接近完成”的反驳措辞偏强；无耗时记录只能说明收集完成不保证适配检查完成，不能量化剩余工作。此项记为表达边界，没有判为核心标准失守。

该迁移例使用第一步修改后的快照，不能写成第二步最终技能的调用证据。原三个场景也是第一步快照复验；最终指令仅再次运行仍有残留问题的研究收束题。全部执行共 11 次（6 次首轮、3 次第一步复验、1 次迁移、1 次第二步收束题复验），对应 7 个不同场景，不能当作 11 个独立用户样本。

第二步收束题的最终独立审查认为四项原始标准与新增范围标准均达到。回答保留交接观察作为需求线索，后续只提出能够区分解释的取证，没有替材料角色选择表格或共享页面。该题第一次修正后的“部分达到”记录保留；最后一次达标也只证明这一份输出，没有证明问题从此不会再出现。

最终审查首次读取标准时工具返回了整份标准，包含另外五例标准；未读取其他轮回答、评审或技能源。此读取范围偏差记录在私有评审中，不宣称审查者只看过单题标准。
