# 当前路线：个人技能集合

更新：2026-10-25。用户明确要求移除安装器，将仓库作为多个个人技能的集合。此路线取代“冻结运行时并保留备用”“真实任务之后进行原生插件实验”等旧安排，依据见 [ADR 0004](decisions/0004-personal-skill-collection.md)。

## 当前工作

- 保持 skills 下每个技能独立可用，只维护一份作者源。
- 通过个人真实任务识别问题并改进具体技能，不按安装、分发或插件基础设施安排里程碑。
- 新技能来自实际重复需求，先验证价值再补充必要资源，不预先铺设占位技能。
- 保留轻量格式、引用与材料结构检查；需要时才进行有针对性的行为试跑。
- 研究原始材料与备份留在 .local，可提交的只是脱敏发现与明确标注的合成示例。

[同日真实项目联网对照](evidence/online-ab-20261025-summary.md) 的首轮普通组与技能组在分析深度、发散质量和竞品启发上均相近。已有的局部优势与反向遗漏不能证明净收益；后续改进围绕真实认知增量与最强现有替代展开，不因完成联网研究而启动产品开发或分发建设。

[workbench-01](evidence/workbench-01-summary.md) 的普通组与技能组主要建议相近，未证明明显净增益。[research-02](evidence/research02-summary.md) 支持部分受控行为符合要求，但不代表真实用户价值、在线竞品研究或自动触发已验证。这些历史结论保留，不以结构整理改变它们。

下一步随实际使用记录哪些解释改变了产品判断、哪些竞品启发可迁移、哪些步骤增加了不必要负担。按观察定向改进，不要求凑固定样本数或达到某个评分才可以继续使用技能。

## 产品研究的下一轮改进

按依赖与价值推进，非时间排期；结构取舍见 [ADR 0005](decisions/0005-layered-product-research.md)。

- **P0 关键缺口**：已在作者源加入同任务的最强替代检验、选样偏差检查、真实认知基准、专家证据区分，以及反证与选择的关联。写入指令不等于旧问题已解决，实际行为记录见 [验证报告](validation-report.md)。
- **P1 过程可靠性**：入口按深度与意图路由；复杂任务用轻量问题/假设地图关联原始证据、关键未知与更新，允许回退，交付前检查相关性与反证。简单问题不强制执行完整流程，无新增运行时或状态服务。
- **P2 真实认知价值**：后续选择个人真实任务，按 [效果评估](skill-evaluation.md) 对照普通回答与技能回答，记录新增认知、建议与实际决定、耗时和核查/追问负担。保留失败与修正前后输出；目前未完成本轮真实任务对照与用户反馈，不预设提升比例。

作者源调整不会自动同步使用副本；本轮已按用户后续明确授权，在备份和核查后完成本机副本同步，并将仓库变更纳入提交推送范围。模块具备独立触发、明确输入输出和独立验证价值后才考虑另拆技能，不先建设研究管理工作台。

2026-10-25 用户已授权将现有仓库调整同步到远端；此授权不包含版本发布或后台更新。没有安装器重建、原生插件验证、市场分发或后台更新的后续计划；如用户将来提出新的实际需求，再单独评估。
