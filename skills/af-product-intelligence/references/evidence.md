# 证据与推理规则

重要主张就近关联可定位的原始证据与支持范围。需要跨来源核查或持续更新时，为主张分配唯一 claim_id，记录来源标题、URL 或本地文档/段落、作者（可得时）、发布/更新日期、实际获取日期、支持内容摘要、适用范围、置信度和局限；短答可在正文直接引用，无需另建完整账本。日期不可得填“未知”；离线材料的获取日期是实际读取日期，不能假装在该日访问过原网站。

区分五类内容：

| 类别 | 要求 |
| --- | --- |
| 事实 | 直接证据支持到陈述的具体程度，引用不支持的部分拆成推断 |
| 来源观点 | 归属于明确作者及原始语境，不当成市场事实 |
| 推断 | 列出证据编号、推理及至少一个替代解释 |
| 假设 | 写出待验证前提、证伪方式和适用范围 |
| 建议 | 解释决策理由、成本/收益、条件和下一个实验 |

核查时优先一手来源，但厂商自述只能证明其公开宣称的功能，不能单独证明实际效果。用户评价是特定样本的体验，不直接推出总体比例。转述找不到原文时标为二手，降低置信度。搜索摘要和无法读取的链接不能支撑“已核实”关键事实。

对价格、商业条款、功能和市场份额记录时间与地域；过期资料只能证明历史情况。多个来源相互矛盾时并列陈述，标出尚不能解释的分歧。没有数据不写数值；由用户给定或自行提出的实验阈值标为假设。

专家观点须区分真实原始来源、研究者对理论的应用与 Agent 模拟专业视角。只有前者可归属于具名专家，且不能暗示其对当前方案亲自评审或背书。模拟评审标明不是访谈或真人参与，异议和修正建议也不当成经验事实。

对影响判断的专家依据，保留原始定位、来源实际说了什么、原适用情境及本次迁移前提；作者声望不能补足证据。引用具名理论时可以归属理论本身，但方案分析归于研究者。模型模拟或多个角色一致意见不增加独立证据数量；找不到原始专家材料时明确缺口，不虚构访谈或共识。

关键结论有冲突材料时，关联到同一主张，记录支持、反驳还是仅限制适用范围，并检查时间、定义和样本差异。证据账本可追加“影响的判断/选择、未解冲突/下一项区分证据”，避免把来源数量当可信程度；反证与选择更新见 [认知增量与反证](learning-and-challenge.md)。

图表继承相同证据要求。定性机会图/机制图注明研究者推断及适用条件；没有量化依据不添加精确坐标、评分、比例或效果提升。资料未覆盖的创新方向可以提出，明确作为假设并给出可验证的机制，不要求先证明它才允许探索。

先完成证据映射，再检查：重要事实覆盖率是否 100%，引用是否真正支持陈述，模拟材料是否全部标记，是否存在伪造来源或未授权操作。未满足时修改陈述或明确保留未知，不能为补齐表格发明内容。
