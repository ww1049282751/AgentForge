# Skill Spec

创建或显著改变职责时按实际任务填写，可直接在会话交付，不要求保存为配置文件。局部修复无需补齐本模板。

| 字段 | 设计内容 |
| --- | --- |
| Goal | 要改善的具体任务、能力缺口与完成后可观察的变化 |
| Scope | 包含及不包含的职责，与已有能力的关系 |
| Trigger | 典型适用请求、容易误触发的邻近任务和排除条件 |
| Inputs | 必要输入、可自行取得的信息、关键未知 |
| Outputs | 交付物、使用方式及完成条件 |
| Workflow | 影响结果的判断、分支、必要步骤和停止条件 |
| Resources | 实际需要的参考、模板、示例或脚本及何时加载；无需则说明 |
| Constraints | 证据、隐私、写入、外部操作权限及保留用户内容的边界 |
| Evaluation | 正例、负例、权限边界、失败信号和执行证据 |
| Maintenance | 什么反馈或变化值得更新，哪些能力需要回归 |

另记必要性判断：现有技能、一次性提示、参考文档或小脚本能否解决，为什么选择当前方案。未知写为未知，不凭模板补造事实。
