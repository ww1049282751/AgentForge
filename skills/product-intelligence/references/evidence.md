# 证据与推理规则

每个重要事实分配唯一 claim_id，并记录来源标题、URL 或本地文档/段落、作者（可得时）、发布/更新日期、实际获取日期、支持内容摘要、适用范围、置信度和局限。日期不可得填“未知”；离线材料的获取日期是实际读取日期，不能假装在该日访问过原网站。

区分五类内容：

| 类别 | 要求 |
| --- | --- |
| 事实 | 直接证据支持到陈述的具体程度，引用不支持的部分拆成推断 |
| 来源观点 | 归属于明确作者及原始语境，不当成市场事实 |
| 推断 | 列出证据编号、推理及至少一个替代解释 |
| 假设 | 写出待验证前提、证伪方式和适用范围 |
| 建议 | 解释决策理由、成本/收益、条件和下一个实验 |

核查时优先一手来源，但厂商自述只能证明其公开宣称的功能，不能单独证明实际效果。用户评价是特定样本的体验，不直接推出总体比例。转述找不到原文时标为二手，降低置信度。搜索摘要和无法读取的链接不能支撑“已核实”关键事实。

对价格、商业条款、功能和市场份额记录时间与地域；过期资料只能证明历史情况。多个来源相互矛盾时并列陈述，标出尚不能解释的分歧。没有数据不写数值；由用户给定或自行提出的实验阈值标为假设。

先完成证据映射，再检查：重要事实覆盖率是否 100%，引用是否真正支持陈述，模拟材料是否全部标记，是否存在伪造来源或未授权操作。未满足时修改陈述或明确保留未知，不能为补齐表格发明内容。
